Place your new logo image(s) here using the exact filenames below.

Preferred format: SVG for sharp, scalable rendering. If you only have PNG/JPG, the component will fall back to PNG.

Filenames (case-sensitive on some systems):
- `car-rental-logo.svg`  (preferred)
- `car-rental-logo.png`  (fallback)

Recommendations:
- Sidebar icon: 48×48 px (or an SVG that scales) with transparent background.
- Topbar/full logo: 160×48 px recommended; SVG will scale cleanly on retina displays.
- Remove any white/solid background from the image to keep the site's theme clean.

Example path: `public/images/car-rental-logo.svg`

After adding the file, run:

```powershell
npm run build
```

Then hard-refresh the browser (Ctrl+F5) to see the updated logo in the app.
